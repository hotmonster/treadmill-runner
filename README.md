# treadmill-runner · 跑步机 / 健步机 App 下架后的自救手册与数据规格

官方 App 下架了、蓝牙遥控器找不到了、说明书早丢了——机器还能跑，但配套的那一层没了。这个仓库把「怎么继续用」和「怎么自己做一个记录 App」一次讲清楚。

**当前状态：文档与规格已发布，代码整理中。**

## 这套文档适合谁

符合下面任意一条，这里的文档就能直接用：

- 跑步机的**官方 App 已经下架**，装不上、登不上，历史数据也想拿回来
- **蓝牙遥控器不见了**，或者实体遥控器按了没反应、配对不上
- 想自己把手机的**跑步机遥控**做出来，但不知道从哪下手、协议怎么抓
- 想要**跑步机课程语音播报**、周报、累计天数，但不依赖厂商服务器
- 手上只有机器，**跑步机说明书**丢了，不知道型号参数怎么看、跑带怎么调
- 官方 App 还在但不好用，想找一个能长期维护的替代

> 从没遇到过这些问题？那你大概不需要这个仓库——它不提供任何破解、刷机或绕过安全装置的方法。

## 为什么值得自己做一个

家用跑步机 / 走步机的官方 App 经常停止维护：服务器一停，登录、课程、历史数据全部失效，机器本身却还能用十年。自建客户端是唯一可持续的路径，难点不在 UI，而在四件事：

1. 设备控制协议不公开，需要抓包
2. 暂停 / 继续的计时语义容易做错，数据会丢
3. 周报、累计天数、趋势没有统一定义，各家算出来都不一样
4. 语音播报什么时候说、说什么，直接决定用不用得下去

这四件事本仓库都给了具体口径和踩坑记录。

## 不适用范围

商用健身房的会员与结算系统、需要接入厂商云端的场景、需要破解固件或绕过安全装置的场景。电动车、划船机等非跑步带类器械的协议不通用，请勿套用。
