# treadmill-runner · 跑步机 / 健步机 运动记录 App 设计与数据规格

把一套个人自用的跑步机配套 App 的产品规格、数据模型和踩过的坑整理成公开文档，方便在写同类应用（尤其是家用跑步机、健步机的蓝牙/红外遥控 + 运动记录）时少走弯路。

**当前状态：文档与规格整理中，代码尚未开源。** 本仓库先发布「能直接照着实现的东西」：数据模型、周报口径、语音报数的播报规则、暂停恢复的语义，以及几个实测遇到的问题。代码整理完成后会补进来。

## 为什么会有这个仓库

家用跑步机/健步机的官方 App 经常下架或停止维护，机器本身还能用，但历史数据、周报、语音播报这些没人做了。自己写一个配套 App 是可行的，难点不在 UI，而在于：

- 设备控制协议不公开，需要自己抓包
- 暂停/继续的计时语义容易做错，数据会丢
- 运动数据的统计口径（周报、累计天数、趋势）没有统一定义
- 语音播报什么时候说、说什么，直接影响使用体验

## 适用与不适用

适用：家用跑步机、走步机、健步机的个人配套 App。  
不适用：商用健身设备的会员系统、需要接入厂商云端的场景。
